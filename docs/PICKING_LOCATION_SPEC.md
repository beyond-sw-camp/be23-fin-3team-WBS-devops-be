# 🛒 피킹 위치 추천 스펙

**버전**: 1.0  
**목적**: 출고 시 어떤 위치의 재고를 먼저 피킹할지 자동으로 추천하는 기준과 흐름 정의  
**작성일**: 2026-05-09

---

## 1. 개요

피킹 위치 추천은 출고지시서 또는 피킹리스트 생성 시  
상품별로 어느 로케이션에서 수량을 꺼낼지 자동으로 결정하는 기능이다.

이 기능의 목표는 다음과 같다.

- 출고 가능한 재고를 빠르게 확보
- 작업자가 여러 위치를 불필요하게 오가지 않도록 최소화
- 가용재고와 예약재고 기준을 분명히 반영
- 한 위치 부족 시 여러 위치로 분산 피킹 가능하게 지원

---

## 2. 적용 시점

피킹 위치 추천은 다음 상황에서 사용된다.

- 출고지시 승인 후 피킹리스트 생성 시
- 웨이브 생성 시 출고 상품 위치 배정 시
- 수동 피킹 위치 재계산 시

---

## 3. 입력 조건

추천 시 시스템이 보는 주요 값은 다음과 같다.

- 상품 ID
- 출고 대상 수량
- 창고 ID
- 위치별 가용재고
- 예약재고 반영 여부
- 출고 가능한 재고 상태 여부

---

## 4. 기본 원칙

### 4.1 가용재고 우선
- `available_qty` 기준으로 피킹 가능 수량 계산
- 이미 예약된 재고는 중복 피킹 대상에 포함하지 않음

### 4.2 한 위치 우선
- 한 로케이션에서 출고 수량을 모두 충당할 수 있으면 단일 위치 우선
- 작업 동선 단순화를 위해 분산 피킹은 차선

### 4.3 분산 피킹 허용
- 한 위치 수량이 부족하면 여러 로케이션으로 나누어 추천
- 부족 수량만큼 다음 후보 위치를 이어서 배정

---

## 5. 추천 우선순위

피킹 위치는 일반적으로 다음 순서로 추천한다.

### 5.1 1순위 — 동일 상품 재고가 충분한 단일 위치
- 한 위치에서 전량 충당 가능하면 우선 배정

### 5.2 2순위 — 위치 코드상 먼저 접근 가능한 위치
- 여러 위치가 있으면 정렬 기준(로케이션 코드, 랙 순서 등)에 따라 우선순위 부여

### 5.3 3순위 — 부족분 분산 위치
- 첫 위치에서 부족한 수량은 다음 위치에서 이어서 충당

---

## 6. 분산 피킹 예시

예를 들어 출고 필요 수량이 120개일 때:

- A-01 : 70개
- A-02 : 30개
- B-01 : 40개

추천 결과:

- A-01 → 70
- A-02 → 30
- B-01 → 20

즉 필요한 수량을 만족할 때까지 순서대로 배정한다.

---

## 7. 제외 조건

다음 위치는 추천 대상에서 제외한다.

- 비활성 위치
- 가용재고 0
- 출고 불가 상태 재고만 존재하는 위치
- 다른 작업에서 이미 선점된 위치
- 창고/상품 조건과 맞지 않는 위치

---

## 8. 추천 실패 케이스

다음 경우 자동 추천이 실패하거나 부분 추천이 된다.

- 전체 가용재고가 출고 필요 수량보다 적음
- 상품이 어느 위치에도 적재돼 있지 않음
- 재고 상태가 전부 출고 불가
- 동시 작업으로 위치가 먼저 선점됨

이 경우 시스템은
- 부분 추천 결과를 만들거나
- 출고 불가 / 재고 부족 상태로 전환한다

---

## 9. 시스템 흐름

```text
출고지시 승인 / 웨이브 생성
  ↓
상품별 필요 수량 확인
  ↓
창고 내 위치별 가용재고 조회
  ↓
피킹 가능 위치 후보 추출
  ↓
단일 위치 가능 여부 판단
  ↓
부족 시 여러 위치로 분산 배정
  ↓
피킹리스트 생성
```

---

## 10. 기대 효과

- 출고 피킹 속도 향상
- 작업자 이동 동선 최소화
- 재고 부족 조기 감지
- 웨이브 및 피킹리스트 자동화 정확도 향상

---

## 11. 관련 코드 영역

| 역할 | 위치 |
|------|------|
| 출고 처리 서비스 | `OutboundService` |
| 피킹리스트 생성 | 피킹/웨이브 관련 서비스 |
| 재고 조회 | `InventoryRepository` / `InventoryService` |
| 출고 진행 상태 반영 | `OutboundDispatch` / `PickingList` 관련 로직 |
