# 📦 적치 위치 추천 스펙

**버전**: 1.0  
**목적**: 입고 완료 후 상품을 어느 위치에 적치할지 자동 추천하는 기준과 처리 흐름 정의  
**작성일**: 2026-05-09

---

## 1. 개요

적치 위치 추천은 입고된 상품을 창고 내 어떤 로케이션에 배치할지 자동으로 판단하는 기능이다.  
상품의 속성(협력사, 카테고리, 불량 여부)과 창고 구조(구역, 랙, 로케이션), 현재 적재 상태를 함께 고려한다.

이 기능의 목표는 다음과 같다.

- 동일 성격의 상품을 일관된 위치에 보관
- 협력사/카테고리 기반 보관 정책 반영
- 빈 공간이 아닌 정책상 맞는 공간을 우선 사용
- 창고 운영자가 수동 판단하는 시간을 줄임

---

## 2. 적용 시점

적치 위치 추천은 다음 상황에서 사용된다.

- 일반 입고 검수 완료 후 적치 대상 생성 시
- 반품 입고 후 적치 필요 시
- 불량 판정 수량을 별도 위치에 보관해야 할 때
- 수동 적치 위치 추천 API 호출 시

---

## 3. 추천 목적 구분

적치 추천은 목적(`PlacementPurpose`)에 따라 다른 규칙을 적용한다.

| 목적 | 의미 |
|------|------|
| `NORMAL` | 정상 상품 일반 적치 |
| `DEFECT` | 불량 상품 보관 |
| `RETURN` | 반품 상품 보관 |
| `DISPOSAL` | 폐기 대상 상품 보관 |

---

## 4. NORMAL 적치 추천 규칙

정상 상품은 일반창고(`NORMAL`) 안에서 추천된다.

### 4.1 1순위 — 같은 상품이 이미 있는 위치
- 같은 `productId` 재고가 이미 존재하는 로케이션 우선
- 동일 상품을 여러 위치에 분산시키지 않고 최대한 합적

### 4.2 2순위 — 카테고리 존 + 협력사 랙 교집합
- 상품 카테고리에 연결된 zone
- 상품 협력사에 연결된 rack
- 두 조건을 동시에 만족하는 위치를 우선 추천

### 4.3 3순위 — 카테고리 존 내 빈 위치
- 협력사 전용 랙이 없더라도
- 해당 카테고리 구역 안에서 적재 가능한 빈 위치를 추천

### 4.4 4순위 — 같은 창고 내 가용 위치
- 위 조건을 만족하는 위치가 없으면
- 같은 창고 내 남은 적재 가능 위치를 차선으로 추천

---

## 5. DEFECT / RETURN / DISPOSAL 적치 추천 규칙

정상 상품과 달리 목적성 창고/구역 우선 정책을 적용한다.

### 5.1 불량 적치 (`DEFECT`)
- 불량 보관용 zone 또는 defect 성격의 위치 우선
- 같은 상품 불량 재고가 이미 있는 위치가 있으면 우선 합적

### 5.2 반품 적치 (`RETURN`)
- 반품창고 또는 반품 보관 zone 우선
- 반품 상품 전용 위치가 있으면 우선 추천

### 5.3 폐기 적치 (`DISPOSAL`)
- 폐기창고 또는 폐기 보관 zone 우선
- 폐기 처리 대상 상품은 일반 보관 위치로 추천하지 않음

---

## 6. 적재 가능 여부 판단

추천 위치는 단순 빈칸이 아니라, 실제 적재 가능한지까지 검증해야 한다.

검증 기준:

- 로케이션 활성 여부
- 최대 적재량(`max_capacity`)
- 현재 적재 수량 대비 잔여 용량
- 동일 배치 내 다른 품목이 먼저 선점했는지 여부

잔여 용량이 부족하면 추천 후보에서 제외한다.

---

## 7. 추천 결과 우선순위

추천 결과는 다음 기준으로 정렬된다.

1. 동일 상품 위치 여부
2. 목적에 맞는 zone/rack 일치 여부
3. 잔여 용량 충분성
4. 위치 코드 정렬 순서

즉, 단순히 빈 공간이 많은 곳이 아니라  
**정책상 맞는 위치를 먼저 보여주고 그 안에서 용량을 본다.**

---

## 8. 추천 실패 케이스

다음 경우 자동 추천이 실패할 수 있다.

- 상품의 카테고리 정보 없음
- 상품의 협력사 정보 없음
- 목적에 맞는 zone/rack 미구성
- 창고 내 적재 가능 위치 부족
- 동일 배치에서 다른 품목이 먼저 위치를 선점

이 경우 시스템은 추천 실패 사유를 메시지로 반환하고, 사용자가 수동 지정할 수 있게 한다.

---

## 9. 시스템 흐름

```text
입고/반품/불량 처리 완료
  ↓
적치 대상 품목 확인
  ↓
PlacementPurpose 결정
  ↓
상품 정보 조회 (카테고리 / 협력사)
  ↓
창고 구조 조회 (zone / rack / location)
  ↓
후보 위치 탐색
  ↓
잔여 용량 검증
  ↓
우선순위 정렬
  ↓
추천 위치 반환
```

---

## 10. 기대 효과

- 적치 위치 선정 시간 단축
- 협력사/카테고리 기반 창고 운영 표준화
- 동일 상품 위치 분산 최소화
- 불량/반품/폐기 재고 혼입 방지
